# blausues.github.io

내가 만든 앱의 소개, 개인정보처리방침, 문의 페이지. GitHub Pages로 https://blausues.github.io 에 그대로 올라가요.

```
index.html              앱 목록
assets/style.css        공통 스타일 (앱과 같은 색)
assets/fonts/           Galmuri14 (한글 2,350자만 남긴 웹 폰트)
nature-dex/             생물 도감
  index.html            앱 소개
  privacy/index.html    개인정보처리방침 → App Store Connect '개인정보 처리방침 URL'
  support/index.html    문의 → App Store Connect '지원 URL'
```

새 앱을 만들면 `nature-dex/`를 복사해서 폴더 이름(영어)과 내용을 바꾸고, 첫 화면 `index.html`에 한 줄 추가해요.
처리방침은 앱마다 쓰는 권한이 달라서 따로 둬요.
